This repository is a **public support/issue surface only**. It does not contain the extension source code.

- Use this repo to receive, clarify, and triage user bug reports, compatibility/site requests, and support questions.
- Do not attempt product implementation here.
- Product/source changes belong in the private `corneliusbrackett/TabletopDiceRoller` repository and should be tracked there as actionable GitHub Issues.
- Preserve reporter evidence, browser/version/site context, reproduction steps, and privacy; do not ask users to post secrets or sensitive browsing data.
- When a support report becomes an engineering task, create/link the corresponding source-repo Issue and keep the public thread concise about status without exposing private implementation details.
